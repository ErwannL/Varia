# examples/external-config/

Configurations Varia des projets externes, gardées **hors** des projets clonés (lancées avec
`varia --config <fichier>`) pour ne jamais modifier le projet cible.

- `immutability-helper.varia.yml` — projet externe Jest (J1, D-014).
- `destr.varia.yml` — projet externe Vitest/ESM (J2, D-021).
