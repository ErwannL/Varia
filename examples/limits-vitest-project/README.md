# examples/limits-vitest-project/

Projet d'exemple Vitest (ESM, TypeScript), ajouté en J3 : `grow(count)` épuise la mémoire pour une
valeur non entière ≥ 0. Vérifie que `mutations.limits.memory_mb` est appliqué aussi sous Vitest (A-03).
Dossiers `src/` et `tests/` : contenu lu comme données par Varia (pas de README).
