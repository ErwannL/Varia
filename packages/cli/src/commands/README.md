# src/commands/

Commandes du CLI regroupées par usage : `run.ts` (baseline, plan, fuzz, test, replay, ci),
`results.ts` (report, accept, compare, oracle suggest), `admin.ts` (init, config, doctor, clean,
prune, db, list, version, dashboard), `scaffold.ts` (squelettes d'adaptateur et d'extension, gabarits
dans `../scaffold/`). Outils communs : `../shared.ts`.
