# pages/

Pages du niveau 1 (CDC §26) : vue d'ensemble, runs, issues, détail d'issue, mutations, détail de
mutation, non couvert, 404. Niveau 2 : arbre Run → Dossier → Fichier → Test → Call site → Mutation →
Erreur (`Tests.tsx`, `Tree.tsx`, fil d'Ariane `Trail.ts`), capacités et limites (`Capabilities.tsx`),
historique, comparaison, acceptations, couverture. Toutes les listes sont paginées côté serveur, page
et filtres dans l'URL (`usePaging`).
