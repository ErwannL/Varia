## FAIT

- Protocole 1.2 (D-037) : messages zod ⇒ JSON Schema, jeu de conformité rejoué par les sondes JS,
  Python, PHP et Java ; majeure inconnue ⇒ `UNSUPPORTED_PROBE`.
- Adaptateurs Mocha, Pytest, PHPUnit, JUnit, custom (D-038 … D-042), chacun avec projet d'exemple,
  suite de conformité, scénarios §5, README, couverture.
- Extensions (D-038, D-045) : hôte en thread, appels synchrones bornés, version déclarée.
- `varia scaffold` (D-044), matrice de capacités générée et test de fumée de mutation robuste aux
  refus de la sonde (D-043), tableau de bord (lanceur, extensions, `PLUGIN_FAILURE`).

## PAS FAIT

- Section « extensions » dans les rapports HTML et Markdown (le JSON v4 et le tableau de bord l'ont).
- Chargement d'un adaptateur TypeScript externe sans modifier Varia (contournement documenté :
  adaptateur `custom`).

## NON SUPPORTÉ

- PHPUnit : cibles asynchrones (scénario 8) — NOT FEASIBLE, PHP n'a ni promesse ni rejet non géré.
- Fixtures de conformité non rejouables, listées et jamais comptées réussies : Python 1
  (`values/set`), PHP 6, Java 5 (`docs/probe-protocol.md` §13).
- Capacités non déclarées par les adaptateurs : `UNSUPPORTED (NOT_DECLARED)` dans
  `docs/adapter-capabilities.md` ; `testParameters` reste `NOT_VERIFIED (NO_SMOKE_TEST)` partout.

## LIMITATIONS

- PHPUnit : fonctions globales, `require` direct, méthodes non publiques non observées.
- Pytest : `sys.exit` = SystemExit synchrone (UNEXPECTED_FAILURE), seul `os._exit` ⇒ CRASH.
- JUnit : constructeurs non observés ; console standalone 1.11.4 remplace la version du projet ;
  préparation ~5–10 s par run.
- Extensions : thread, pas d'isolation de sécurité forte.
