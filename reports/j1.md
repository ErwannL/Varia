## PAS FAIT / NON SUPPORTÉ (J1)

- ESM natif (`UNSUPPORTED_PROBE`), méthodes de classes, mocks comme cibles (J2).
- `unhandledRejection` hors du call site : **non détecté** (limite affichée) — écart à la partie B
  (« rejet non attendu ⇒ CRASH dès J1 ») : NOT FEASIBLE en J1 sans instrumenter l'environnement de
  test de Jest ; seule la détection au call site existe (`TARGET_REJECT`).
- Écritures d'acceptations, historique/comparaison, JUnit/SARIF/HTML, incrémental, cache (J2).
- `UNOBSERVED_COVERED_TARGET` (nécessite une couverture) : non implémenté.

## LIMITATIONS

- Estimation de durée : borne haute grossière (mutations × durée d'un processus de baseline).
- `testParameters` non vérifiable génériquement par `doctor` (`NOT_VERIFIED`).
- Couverture non mesurée pour le code exécuté hors processus Vitest (sonde, transform, superviseur) :
  couvert par les tests d'intégration (`docs/notes/couverture.md`).
- `VARIA_PUBLIC_URL` documentée mais non lue ; embarquement d'un Varia local dans une page publique
  bloqué par Chromium (Local Network Access).

## RISQUES

- Durée : ~0,8 à 1,1 s par mutation ; les gros projets exigent `--quick`, `--max-mutations`, budgets.
- Faux positifs `UNEXPECTED_FAILURE` sur des erreurs volontaires (`Error` générique, cf. projet externe) :
  à classer via `oracle.handled_errors` (motif de message) — `oracle suggest` en J2.
